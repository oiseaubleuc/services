Hoe toe te voegen aan Gmail:

  1. Kopieer de HTML code hieronder
  2. Ga naar Gmail → Instellingen (⚙️) → Alle instellingen bekijken
  3. Scroll naar "Handtekening"
  4. Klik op "Nieuwe handtekening maken"
  5. Klik op het pictogram ⋮ (meer opties) en kies "HTML bewerken"
  6. Plak de gekopieerde HTML code
  7. Klik op "Opslaan"
  8. Selecteer de handtekening als standaard voor nieuwe e-mails
